# Phaser Game Starter

Progetto base per un gioco in browser usando **TypeScript** e **Phaser 3**.

## Comandi

- `npm install` - installa le dipendenze
- `npm run dev` - avvia il server di sviluppo
- `npm run build` - genera la build di produzione
- `npm run preview` - preview della build di produzione

## Struttura

- `index.html` - entry point del gioco
- `src/main.ts` - inizializza Phaser
- `src/game.ts` - configurazione del gioco
- `src/scenes/GameScene.ts` - logica principale

## Prossimi passi

- aggiungi sprite in `src/assets`
- crea nuove scene in `src/scenes`
- organizza le classi in `src/systems` e `src/components`

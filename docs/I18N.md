# 🌍 Internazionalizzazione (i18n) — Zombie Road: Last Escape

Tutti i testi rivolti al giocatore sono **esternalizzati** in dizionari per lingua. Il codice non
contiene letterali: chiama `t('chiave')`. L'italiano è la **locale di default e canonica**.

## Lingue supportate

`it` (default · canonica) · `en` · `es` · `fr` · `de` · `pt`.

Aggiungerne una è un solo file (vedi sotto). Cinese/giapponese/coreano/arabo richiederebbero un
font con quei glifi (il chrome usa `Courier New`, vedi *Insidie*) e — per l'arabo — gestione RTL:
fuori dal perimetro attuale.

## Come è fatto

| Pezzo | File |
|---|---|
| Funzione di traduzione `t()` + elenco lingue `LANGS` | [`src/i18n.ts`](../src/i18n.ts) |
| Dizionari per lingua | [`src/locales/`](../src/locales/)`<lang>.ts` |
| Preferenza persistente `language` | [`src/Settings.ts`](../src/Settings.ts) |
| Selettore lingua (UI) | [`src/scenes/SettingsScene.ts`](../src/scenes/SettingsScene.ts) → `buildLanguage`/`cycleLanguage` |

### `t(chiave, params?)`

```ts
import { t } from '../i18n';

t('menu.continue')                         // → "CONTINUA" / "CONTINUE" / …
t('shop.money', { n: 120 })                // segnaposto {n} → "★ 120 monete"
t('hud.comboMult', { n: 4, m: 2 })         // più segnaposto
```

- Cerca la chiave nel dizionario di `Settings.language`.
- **Fallback** → italiano → la chiave stessa (in `dev` logga un warning sulla chiave mancante).
- Interpolazione: ogni `{nome}` è rimpiazzato dal corrispondente `params.nome`.

### Dati con testo = chiavi, non stringhe

`GameData` (`VEHICLES`/`WEAPONS`/`SURVIVORS`), `BOSS_CONFIG` ed `ENVIRONMENTS` (in `GameScene`),
`SHOP_ITEMS` (in `ShopScene`) e le gallerie di `DebugScene` memorizzano **chiavi i18n** nei campi
testuali (`name`/`desc`/`label`/`ability`), risolte con `t()` al momento del render.

I **numeri** nelle descrizioni (es. abilità sopravvissuti) NON si scrivono nelle traduzioni: si
passano via params da un'unica fonte. Esempio (sopravvissuti):

```ts
// GameData.ts — i valori vivono qui, una volta sola
{ key: 'mechanic', name: 'survivor.mechanic.name', ability: 'survivor.mechanic.ability',
  abilityParams: { hp: 8, s: 5 }, color: '#44aaff' }

// it.ts — la traduzione usa i segnaposto
'survivor.mechanic.ability': 'Ripara {hp}hp al comp. peggiore ogni {s}s',

// ShopScene — risoluzione
t(s.ability, s.abilityParams)
```

## Ricette

### Aggiungere una stringa nuova

1. Scegli una chiave a namespace (`scena.elemento`, es. `shop.refundAll`).
2. Aggiungila **prima in [`it.ts`](../src/locales/it.ts)** (locale canonica), poi negli altri 5 file.
3. Nel codice: `t('shop.refundAll')` (mai il letterale).
4. Se contiene numeri di gameplay, usa `{segnaposto}` e passali via `params`.

### Aggiungere una lingua

1. Crea `src/locales/<code>.ts` copiando `it.ts` e traducendo i valori (lascia chiavi e simboli).
2. In [`src/i18n.ts`](../src/i18n.ts): importa il file, aggiungilo a `DICTS` e a `LANGS` (con l'etichetta nella lingua stessa).
3. In [`src/Settings.ts`](../src/Settings.ts): aggiungi il codice a `Lang` e a `LANGUAGES`.

Il selettore in Impostazioni e l'auto-detect del browser si aggiornano da soli.

### Cambiare lingua a runtime

Impostazioni → **LINGUA** → frecce ◂ ▸. Al cambio si salva la preferenza e si fa `scene.restart()`
della schermata Impostazioni (Phaser non ri-traduce gli oggetti già disegnati).

**Cambio in pausa (ESC durante la partita).** L'HUD (salute, carburante, punteggio, componenti…)
vive in `GameScene`, congelata *sotto* l'overlay Impostazioni: non verrebbe ridisegnato dal restart
del solo overlay. Per questo `SettingsScene.cycleLanguage()`, se `fromKey === 'GameScene'`, chiama
`GameScene.refreshLanguage()` → `HudController.build()` (che **distrugge e ricrea** i propri oggetti,
tracciati in `objects`) + `updateHUD()` per ripopolare i valori, e ri-traduce la barra del boss se
attivo. Le **label dei componenti** sono memorizzate come chiavi (`comp.engine`…) proprio per essere
ri-tradotte qui.

## Insidie da conoscere

- **Font / diacritici.** Il chrome usa `Courier New` ([`Ui.ts`](../src/Ui.ts)): copre Latin-1
  (`à á ä ç é è ñ õ ü` …) → le 6 lingue attuali rendono bene. Script non-latini no: servirebbe
  un altro font (impatto sull'[art bible interfacce](ART_BIBLE_INTERFACCE.md)).
- **Overflow di layout.** Tedesco e portoghese sono più lunghi dell'italiano: verifica che le
  etichette nei pannelli a larghezza fissa (negozio, impostazioni) non sforino.
- **Validatori.** `validate-art-bible.mjs` confronta i `name` di GameData con i nomi italiani delle
  art bible **risolvendoli tramite `it.ts`**: la fonte di verità dei nomi italiani è ora `it.ts`.
  Se rinomini un'entità, aggiorna `it.ts` **e** la tabella dell'art bible. I validatori di
  bilanciamento leggono solo i campi numerici → indifferenti ai testi.
- **Niente decimali localizzati.** I numeri sono interpolati grezzi (`0.3`, non `0,3`). Se servisse,
  introdurre `Intl.NumberFormat` per locale è un'estensione futura.

## Cosa NON è tradotto (volutamente)

Il titolo del gioco **ZOMBIE ROAD / Last Escape** (brand) e i simboli/segni dell'UI
(`★ ▸ ● ↯ ⚠ ✓ 🔒` …), che fanno parte dello stile e sono uguali in ogni lingua.
